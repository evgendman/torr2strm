# Version model

Software version: 1.4.9.

Manifest schema: v5.

NFO format: v3.

These version domains are intentionally independent. The v1.4.9 Jellyfin STRM collision fix changes only destination names for colliding files; it does not change manifest records, NFO content/schema, or require a data migration. Keep any future schema version change explicit and independent of the software version.
