# Version model

Software version: 1.4.10.

Manifest schema: v5.

NFO format: v3.

These version domains are intentionally independent. The v1.4.10 Apprise alert refinement adds title-bearing collision summaries and keeps per-file diagnostics in the local journal. It does not change manifest records, NFO content/schema, or require a data migration. Keep any future schema version change explicit and independent of the software version.
